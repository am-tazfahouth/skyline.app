# Weather Content Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize every user-visible string and date/time format on the weather content page and its adjacent screens through the existing ARB/gen-l10n pipeline.

**Architecture:** Direct `AppLocalisation.of(context)!` reads in presentation widgets (same pattern as `SettingsScreen`); date/time patterns declared as ICU messages in ARB so `gen-l10n` emits typed, locale-aware methods; `WeatherFormat.condition` and `AppError.getUserErrorMessage` take an `AppLocalisation` parameter. Language changes propagate automatically via Flutter's `Localizations` inherited widget.

**Tech Stack:** Flutter, `flutter_localizations`, `intl`, `flutter gen-l10n` (config: `l10n.yaml`).

## Global Constraints

- **English code only:** identifiers, comments, and commit messages in English; all user-visible UI strings come from ARB.
- **Zero warnings:** `flutter analyze` must report 0 warnings and 0 infos after every task.
- **TDD:** write/extend the failing test first, run it to see it fail, then implement.
- **Regenerate l10n after every ARB edit:** `flutter gen-l10n` regenerates the committed files under `lib/core/l10n/` (`app_localisation.dart`, `app_localisation_en.dart`, `app_localisation_fr.dart`, `app_localisation_es.dart`, `app_localisation_ar.dart`). These generated files are committed.
- **All four ARB files must stay in sync** (`intl_en.arb` template + `intl_fr.arb`, `intl_es.arb`, `intl_ar.arb`).
- **Debug-only strings** (`AppError.getDebugErrorMessage`) stay English and are never user-visible.
- Spec: `docs/superpowers/specs/2026-08-06-weather-content-localization-design.md`

```dart
    if (weatherCode == 0) return l10n.weatherConditionClear;
    if (weatherCode <= 3) return l10n.weatherConditionPartlyCloudy;
    if (weatherCode <= 48) return l10n.weatherConditionFoggy;
    if (weatherCode <= 55) return l10n.weatherConditionDrizzle;
    if (weatherCode <= 65) return l10n.weatherConditionRain;
    if (weatherCode <= 75) return l10n.weatherConditionSnow;
    if (weatherCode <= 82) return l10n.weatherConditionRainShowers;
    return l10n.weatherConditionThunderstorm;
  }
```

```dart
  factory PeriodConfig.compute({
    required DailyWeatherEntity today,
    required DateTime nextSunrise,
    required DateTime now,
    required ColorScheme colorScheme,
    required AppLocalisation l10n,
  }) {
    final isDay = now.isAfter(today.sunrise) && now.isBefore(today.sunset);

    final String firstLabel;
    final String secondLabel;
    final IconData firstIcon;
    final IconData secondIcon;
    final Color firstColor;
    final Color secondColor;
    final DateTime firstTime;
    final DateTime secondTime;
    final String title;
    final IconData titleIcon;

    if (isDay) {
      firstLabel = l10n.weatherSunSunrise;
      firstIcon = Icons.wb_sunny_outlined;
      firstColor = colorScheme.primary;
      firstTime = today.sunrise;
      secondLabel = l10n.weatherSunSunset;
      secondIcon = Icons.nightlight_round_outlined;
      secondColor = colorScheme.secondary;
      secondTime = today.sunset;
      title = l10n.weatherSunTitle;
      titleIcon = Icons.wb_sunny_outlined;
    } else {
      firstLabel = l10n.weatherSunSunset;
      firstIcon = Icons.nightlight_round_outlined;
      firstColor = colorScheme.secondary;
      secondLabel = l10n.weatherSunSunrise;
      secondIcon = Icons.wb_sunny_outlined;
      secondColor = colorScheme.primary;
      title = l10n.weatherNightTitle;
      titleIcon = Icons.nightlight_round_outlined;
      if (now.isAfter(today.sunset)) {
        firstTime = today.sunset;
        secondTime = nextSunrise;
      } else {
        // Dawn: proxy sunset is approximated as 12h before today's sunrise
        // since Open-Meteo only provides today's data.
        final proxySunset = today.sunrise.subtract(const Duration(hours: 12));
        firstTime = proxySunset;
        secondTime = today.sunrise;
      }
    }

    final midpoint = DateTime.fromMillisecondsSinceEpoch(
      (firstTime.millisecondsSinceEpoch + secondTime.millisecondsSinceEpoch) ~/ 2,
    );

    return PeriodConfig(
      firstIcon: firstIcon,
      firstColor: firstColor,
      firstLabel: firstLabel,
      firstTime: l10n.weatherSunTime(firstTime),
      secondIcon: secondIcon,
      secondColor: secondColor,
      secondLabel: secondLabel,
      secondTime: l10n.weatherSunTime(secondTime),
      chartStart: firstTime,
      chartEnd: secondTime,
      isDay: isDay,
      title: title,
      titleIcon: titleIcon,
      middleLabel: isDay ? l10n.weatherSunZenith : l10n.weatherSunMidnight,
      middleTime: l10n.weatherSunTime(midpoint),
    );
  }
```
